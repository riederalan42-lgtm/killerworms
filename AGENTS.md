# Projektleitlinien

Die technische Spezifikation und Architekturübersicht liegen im Ordner [`spec`](spec/).

Vor Änderungen an Spielstruktur, Rendering, Szenen, Eingaben oder Kernsystemen zuerst [`spec/architecture.md`](spec/architecture.md) prüfen. Die Spezifikation muss bei jeder relevanten Änderung nachgeführt und aktuell gehalten werden.

Für jedes neue oder geänderte Feature müssen passende Tests erstellt oder bestehende Tests erweitert werden. Änderungen gelten erst als abgeschlossen, wenn die zugehörigen Tests erfolgreich sind.
